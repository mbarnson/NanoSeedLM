# Long decode and long prompts on the RTX 4080 (2026-11-06)

**Result.** On the stock path of v0.1.0, the RTX 4080 decodes 4,096 tokens at 44 tokens per second with TCQ3. TCQ3-D4
gives 38, and TCQ4 gives 31. After a prompt of 30,000 tokens, decode stays at 42, 36 and 30. The prompts run at 1,700 to
2,000 tokens per second. These numbers replace the 256-token decodes for the model cards.

**Status.** Current. The PC's part of the long runs for the cards. The M4 Max's part follows on its own page.

## Setup

- PC: RTX 4080 (16 GB), Windows, 128 GB of RAM. Desktop apps only (1.2 GB of VRAM, 11% GPU before the runs), on AC.
- Engine: the v0.1.0 draft's Windows zip (`aff90774`, built from `ff92415`). The packs and their revisions are the
  release's. The runs used the old pack names (TQ3, TQ3-D4, TQ4).
- The stock path: `nslm-serve --ctx 32768 --port 8080`, with `Q4E_PLE_GGUF` set to Unsloth's Q8_0 PLE table, as
  `run-PACK.bat` does it. The expert cache sizes itself.
- Requests: `bench/` on the `agents` branch. Thinking on, temperature 0. Each request ran twice.
  - `long-0k`: a short task (a B-tree module), at most 4,096 tokens.
  - `depth-15k` and `depth-30k`: 15,000 or 30,000 tokens of `nslm/lib_*.c` at `ff92415` (cut by the model's tokenizer),
    then a question, at most 2,048 tokens.

## Results

Decode in tokens per second (run 1 / run 2):

| Pack (cache slots at 32K) | 4,096 tokens, short prompt | 2,048 tokens after 15K | 2,048 tokens after 30K |
|---|---|---|---|
| TCQ3 (3,324) | 43.6 / 44.4 | 42.9 / 40.8 | 42.0 / 44.2 |
| TCQ3-D4 (3,004) | 38.9 / 37.0 | 37.9 / 37.5 | 35.8 / 36.2 |
| TCQ4 (2,518) | 31.4 / 31.4 | 31.2 / 31.5 | 30.1 / 30.3 |

Prompts (run 1 / run 2):

| Pack | 15,072 tokens: tok/s, TTFT | 30,072 tokens: tok/s, TTFT |
|---|---|---|
| TCQ3 | 1,757 / 2,027, 8.7 / 7.6 s | 1,683 / 2,004, 18.0 / 15.1 s |
| TCQ3-D4 | 1,895 / 1,857, 8.1 / 8.3 s | 1,793 / 1,824, 16.9 / 16.6 s |
| TCQ4 | 1,597 / 1,799, 9.6 / 8.5 s | 1,580 / 1,725, 19.2 / 17.6 s |

## Notes

- Each request reached `max_tokens` inside the thinking (finish "length"). So these are decode rates over 2,048 or
  4,096 reasoning tokens. The reasoning reads sensibly: at 30K, TCQ3 walks the C files and questions an edge case.
- TCQ4 is the pack for a 24 GB GPU. On 16 GB it has 16% fewer cache slots than TCQ3-D4, and decode is 17% slower.
- The second run is up to 15% faster on prompts: the page cache then holds more of the pack.
- `nslm-serve` does not draft in v0.1.0. On this GPU the drafts break even, so the numbers would not change much here.
- Raw data on the PC: `G:\devel\qwen4-runs\longbench.log`.

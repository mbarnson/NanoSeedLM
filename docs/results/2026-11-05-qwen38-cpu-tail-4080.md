# The CPU tail on the RTX 4080: slower at every setting (2026-11-05)

**Result.** On the RTX 4080 PC, `--cpu-tail 1` and `2` decode P3 at 31.9 and 26.9 tokens per second, against 37.2
without the CPU tail. The CPU removes 22% and 41% of the expert misses. But one expert on the CPU takes 240 to 340 us,
more than the PCIe 4 copy of about 100 us that it saves. So plan step D4 does not pay on this PC.

**Status.** Current. It closes D4 of the [decode plan](../plans/2026-11-05-qwen38-decode-4080.md).

## Setup

- Machine: pc-cuda's PC (Windows, RTX 4080 16 GB that drives the desktop, Ryzen 7 5800X3D, 128 GB DDR4-3200). No other
  heavy programs ran. The least available RAM was 54.8 GB, and CPU use was at most 47%.
- Commit: `cb3d6b6` (main), a clang-cl build. P3 pinned, the automatic cache (3,305 slots), the code prompt of
  [MTP drafts on the RTX 4080, again](2026-11-05-qwen38-mtp-4080-rerun.md), 256 tokens.

```bash
nslm-qwen4-gen --model P3 --prompt-file CODE --max-tokens 256 --expert-cache-gb -1 --cpu-tail N
```

## Notes

- Each setting gives the same text in both rounds. The text differs between settings: the CPU sums in another order,
  so a rare BF16 rounding flips.
- The GPU waits only 83 to 199 us a layer. The rest of the loss is the cost of the CPU work beside the GPU's copies.
- 8 CPU threads are as fast as 15 on the 5800X3D (8 cores).

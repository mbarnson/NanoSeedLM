# PLE rows on a thread pool: P3 decode 9% faster on the RTX 4080 (2026-11-05)

**Result.** `3f570f3` reads the PLE rows of decode on a pool of threads, one item for each (row, head). On pc-cuda's
RTX 4080, P3 decodes at 33.17 tokens per second against 30.30 before (+9.3%), with the same text. The host PLE
prefetch took 1,075 ms of each 256-token run before, and 2 ms now. With the automatic expert cache, decode is 37.69
tokens per second, and the 2,560 MB display reserve stays free.

**Status.** Current. Two runs of each arm, one PC, one prompt.

## Setup

- Machine: pc-cuda's PC with Windows and an RTX 4080 (16 GB, PCIe 4) that drives the desktop. CPU: Ryzen 7 5800X3D.
  RAM: 128 GB DDR4-3200. No other programs ran. A watchdog stopped the queue below 6 GB of available RAM. It did not fire.
- Model: [Qwen3.8-Flash-Next-NanoSeedLM-P3](https://huggingface.co/txgsync/Qwen3.8-Flash-Next-NanoSeedLM-P3) at
  `5753a67`, pinned experts.
- Arm A: `ecd552f` with `--prompt-file` and `3f570f3`'s `st_dontneed` (local `60f4614`). Arm B: `3f570f3`. Both have
  the same load peak, so the A/B isolates the PLE pool.
- The arms ran in turn: A, B, A, B. Then one profile of each with `Q4E_PROFILE=1` (no CUDA graphs).

```bash
NSLM_VRAM_RESERVE_MB=2560 nslm-qwen4-gen --model P3 --prompt "Write a Python function that merges two sorted lists, with a docstring." --max-tokens 256 --expert-cache-gb 6
nslm-qwen4-gen --model P3 --prompt "Write a Python function that merges two sorted lists, with a docstring." --max-tokens 256 --expert-cache-gb -1
```

## Results

| Run | Decode, tokens/s | Prompt, tokens/s | Peak VRAM | Least available RAM |
|---|---|---|---|---|
| A-1 | 30.22 | 61.7 | 11.75 GB | 55.0 GB |
| B-1 | 33.12 | 62.5 | 11.75 GB | 56.6 GB |
| A-2 | 30.37 | 61.3 | 11.75 GB | 56.8 GB |
| B-2 | 33.21 | 62.7 | 11.75 GB | 56.9 GB |
| B, automatic cache (3,305 slots, about 8.1 GB) | 37.69 | 64.9 | 13.80 GB | 57.7 GB |

All runs give the md5 `0faedf5a`. Each cache-6 run has 78,351 expert hits and 52,786 misses. The automatic cache has
43,396 misses.

## Notes

- The GPU stream is the same in both arms. The gain is the host PLE work that left the critical path.
- With 2 drafts, the PLE rows took 4,315 ms on `ecd552f` ([MTP drafts on the RTX 4080](2026-11-05-qwen38-mtp-4080.md)),
  on a PC near its RAM limit. They take 403 ms on `3f570f3`. So that MTP measurement may have measured the RAM
  pressure more than the drafts. A rerun is planned.
- The automatic cache is 13.6% faster than the 6 GB cache. `nslm-chat` and `nslm-serve` use it.
- Loads took 49.7 to 92.6 s. Load time does not count against a change.

# The VRAM reserve on the RTX 4080: 1,024 MB instead of 2,560 (2026-11-05)

**Result.** On a GPU that drives a display, the Qwen3.8-Flash-Next expert cache kept 2,560 MB of VRAM free, and about
2 GB of it stayed idle. With 1,024 MB kept free, the cache holds about 20% more experts, and decode is 8% to 9% faster
for P3 and for the trellis packs. At 512 MB, decode is slower, because Windows starts to page VRAM. The default for a
display GPU is now 1,024 MB. `NSLM_VRAM_RESERVE_MB` still sets it.

**Status.** Current.

## Setup

- Machine: pc-cuda's Windows 11 PC, RTX 4080 (16.4 GB), the desktop holding 1,268 MiB, nothing else running.
- Build: clang-cl Release of `54a7130`.
- Packs: P3, trellis K = 3 and the trellis mix (`down_proj` at K = 4), as in
  [Trellis experts on the RTX 4080](2026-11-05-trellis-speed-4080.md).
- Runs: `nslm-qwen4-gen`, the code prompt, 256 tokens, the automatic cache, `NSLM_VRAM_RESERVE_MB` set for each run.

## Results

The trellis mix:

| Reserve, MB | Cache slots | Decode, tokens per second | Misses | Peak VRAM, MiB |
|---|---|---|---|---|
| 2,560 (the old default) | 3,823 | 47.36 / 50.07 | 40,123 | 13,833 to 14,005 |
| 1,536 | 4,328 | 53.04 / 53.13 | 36,559 | 14,900 to 15,029 |
| 1,024 (the new default) | 4,581 | 54.35 / 54.38 | 35,189 | 15,396 to 15,541 |
| 768 | 4,707 | 55.20 | 34,260 | 15,670 |
| 512 | 4,834 | 48.86 | 33,329 | 15,753 |

At 1,024 MB against 2,560 MB:

| Pack | Slots | Decode, tokens per second | Gain |
|---|---|---|---|
| P3 | 3,961 | 42.23 (39.1 at 2,560) | +8% |
| Trellis mix | 4,581 | 54.35 (50.07 at 2,560) | +9% |
| Trellis K = 3 | 5,070 | 61.27 (56.05 at 2,560) | +9% |

Each pack wrote the same text at every reserve.

## Notes

- 512 MB gives more slots and fewer misses but is slower: WDDM pages VRAM near the top. So the knee is near 768 to
  1,024 MB with this desktop. 1,024 MB is about twice the margin at the knee.
- A desktop with more monitors, or a program that grows its VRAM while the model runs, needs more. Set
  `NSLM_VRAM_RESERVE_MB` higher then.
- A GPU without a display keeps 512 MB, as before.

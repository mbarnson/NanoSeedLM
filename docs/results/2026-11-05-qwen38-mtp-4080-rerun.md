# MTP drafts on the RTX 4080, again: the same text, slower (2026-11-05)

**Result.** This run uses `3f570f3`, after the PLE and RAM fixes. P3 on the RTX 4080 still gives the same greedy text
with 0 to 3 drafts, so gate MB passes. Drafts make decode slower. With the automatic cache, code decodes at 37.6 tokens per second
without drafts and 29.0 to 32.5 with drafts. Chat decodes at 38.9 without drafts and 24.1 to 32.7 with drafts. Gate MC
fails again, so drafts stay off by default on CUDA.

**Status.** Current. It replaces [the first M3 run](2026-11-05-qwen38-mtp-4080.md), whose PLE reads waited on a PC near
its RAM limit.

## Setup

- Machine: pc-cuda's PC with Windows and an RTX 4080 (16 GB, PCIe 4) that drives the desktop. CPU: Ryzen 7 5800X3D.
  RAM: 128 GB DDR4-3200. No other programs ran. The least available RAM was 55.9 to 57.7 GB. Peak VRAM was 13.8 GB of
  16.38 GB on every run.
- Commit: `3f570f3` (main). Model: [Qwen3.8-Flash-Next-NanoSeedLM-P3](https://huggingface.co/txgsync/Qwen3.8-Flash-Next-NanoSeedLM-P3)
  at `5753a67`, pinned experts.
- As a user runs it: the automatic cache, and the default VRAM reserve (2,560 MB on this GPU). Two rounds. In each
  round, K = 0, 1, 2 and 3 ran in that order.

```bash
nslm-qwen4-gen --model P3 --prompt "Write a Python function that merges two sorted lists, with a docstring." --max-tokens 256 --expert-cache-gb -1 --drafts K
nslm-qwen4-gen --model P3 --prompt "Why do tide pools matter? Answer in three sentences." --max-tokens 256 --expert-cache-gb -1 --drafts K
```

## Notes

- The MTP head and its state copies take about 1.9 GB of VRAM. With the automatic cache, that VRAM comes out of the
  expert cache: 3,305 slots without drafts, 2,368 to 2,461 with drafts. So the misses rise before any verify row.
- At an equal cache of 6 GB, the drafts are also slower: 33.17 tokens per second without drafts, 32.46 at 1 draft and
  30.72 at 2 ([PLE rows on a thread pool](2026-11-05-qwen38-4080-ple-pool.md)).
- The profiles put the cost of each extra row in the router and cache stage: the PCIe copies of its missed experts.
  The admit already copies each missed expert once for all the rows of a forward. So rows that share experts do not
  reduce the copies.
- On the M4 Max, the same drafts make code 31% to 37% faster, because unified memory has no copies
  ([MTP drafts on the M4 Max](2026-11-05-qwen38-mtp-m4max.md)).

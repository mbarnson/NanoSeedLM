# The tail skip and the CPU tail on an RTX PRO 6000 at the 4080's cache (2026-11-05)

**Result.** With the BF16 fix, the CPU tail (`--cpu-tail 7`) changes the decode-row KL by -17%, within the metric's
rounding noise. The tail skip fails gate DL at R = 7, 8 and 9, with or without renormalized weights. On this machine the
CPU tail halves decode (66.5 to 33.4 tokens per second). The GPU-host hand-off adds only about 30 us. The CPU's work is
the cause. One P3 expert takes 1.6 ms of one core, against about 150 us of GPU work to overlap a layer.

**Status.** Current.

## Setup

- Machine: HF Jobs `rtx-pro-6000`. RTX PRO 6000 Blackwell (96 GB, PCIe 5 x16), Xeon Platinum 8559C (192 CPUs), 2 TB
  RAM. The host is shared: the load average was 7 to 11 before the runs.
- Commits: `e5b8c35` (job `6aece14c`) and `4e7877b` (job `6aece564`, hand-off times). Clang build, Linux, CUDA 12.8.
- Model: [Qwen3.8-Flash-Next-NanoSeedLM-P3](https://huggingface.co/txgsync/Qwen3.8-Flash-Next-NanoSeedLM-P3) at
  `5753a67`, pinned experts, an 8.1 GB cache (3,295 slots, the RTX 4080's automatic cache keeps 3,305).
- KL: P3's 1,024 tokens of the wikitext-2 test text, the last 256 decoded one a forward, against P3's own prompt rows.
- Speed: the code prompt of [MTP drafts on the RTX 4080, again](2026-11-05-qwen38-mtp-4080-rerun.md), 256 tokens.

```bash
nslm-qwen4-kld --ref P3 --model P3 --text wiki.test.raw --tokens 1024 --decode 256 --expert-cache-gb 8.1 [--cpu-tail 7 | --tail-skip R]
nslm-qwen4-gen --model P3 --prompt "Write a Python function that merges two sorted lists, with a docstring." --max-tokens 256 --expert-cache-gb 8.1 --cpu-tail 7
```

## Notes

- Gate DC asks that the decode rows' KL rises by at most 1%. The -17% here is noise, not a gain:
  - The engine test shows that the CPU tail computes the GPU's values, up to rare BF16 rounding flips.
  - The same code gives 0.0351 on the RTX 4080 and 0.0364 here.
  - Over 256 rows the mean comes from a few tokens (the median is 0). A 1% bound needs more decode rows or more texts.
- The tail skip (D3) fails gate DL at every setting. Renormalized weights make it worse. It stays off.
- In job `6aece14c`, 15 threads took 143 us an expert. In job `6aece564` they took 467 us. The host is shared.
- The GPU work between the signal and the wait is about 150 us a layer. Rank 7 and later gave 0 to 4 CPU experts a
  layer (1.3 on average), so the GPU waited for the busy layers.
- PCIe 5 copies a missed expert fast, so a CPU share cannot pay on this machine. The RTX 4080's PCIe 4 takes about twice
  as long a copy. So `068617c` changes `--cpu-tail N` to at most N missed experts a layer, lowest rank first.

# Qwen3.8-Flash-Next-NanoSeedLM-P3 on the RTX 4080 (2026-11-04)

**Result.** On an RTX 4080 with 128 GB of RAM, the P3 pack decodes at 9.8 tokens per second with all experts read from
pinned host memory. A VRAM cache of the experts raises this to 29.4 tokens per second at 8 GB and 31.7 at 10 GB. With
`--stream-experts` and a warm file cache, the decode is 12.7 tokens per second at 8 GB. The text was the same in all 14
runs.

**Status.** Current. The prompt has 19 tokens, so the prompt speeds do not show the speed of long prompts.

## Setup

- Machine: RTX 4080 (16 GB, driver 610.88, CUDA 13.3) on PCIe 4.0 x16, Ryzen 7 5800X3D, 128 GB of RAM, Windows 11, on
  AC power. Before each run: about 14.3 GB of VRAM and 108 to 117 GB of RAM free, CPU load 10% to 37% (desktop
  programs, no other compute).
- Build: `eab620d` (the engine of `main` `db0ea15`). The pack is on a Samsung 970 EVO Plus NVMe drive.
- Model: [Qwen3.8-Flash-Next-NanoSeedLM-P3](https://huggingface.co/txgsync/Qwen3.8-Flash-Next-NanoSeedLM-P3) (98.2 GB).
- Command (two runs for each case; the pc-cuda agent ran them):

```bash
build\bin\nslm-qwen4-gen --model PACK --prompt "Why do tide pools matter? Answer in three sentences." --max-tokens 256 [OPTIONS]
```

## Notes

- Without a cache, the decode is 9.8 tokens per second here and 22.1 on an RTX PRO 6000: this board has PCIe 4.0.
- The streamed runs had the pack in the Windows file cache, so they are warm numbers, not NVMe reads. The host copies
  each missed expert on one thread, and each layer waits for its copies. The pinned cache is faster when RAM allows.
- The first 4 GB run loaded in 81.6 s, the first cold read after the runs without a cache. Later loads took 31 to 39 s.
- Windows pinned the 60 GB of experts without an error. The 10 GB cache holds 4,069 experts of 24,576.

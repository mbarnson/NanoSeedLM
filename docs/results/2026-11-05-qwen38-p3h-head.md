# P3H: the MTP head with P = 3 seed experts (2026-11-05)

**Result.** P3H is P3 with its MTP head's routed experts as P = 3 seeds, not 4-bit affine. On the RTX 4080 the head
then joins the expert cache (plan step D1). So draft runs keep 3,008 to 3,101 cache slots, not 2,368 to 2,461. Code
decode with drafts is 7.7% to 9.2% faster, and chat 0.4% to 4.0%. Drafts are still slower than no drafts on the 4080.
On the M4 Max, which has no cache, P3H is not faster, and chat drafts are accepted 4 to 6 points less often.

**Status.** Current.

## Setup

- P3H: `nslm-moe --layers 48-48 --scope gud` (P = 3) searched the head as sparse layer 48. Then `nslm-qwen4-pack
  --base P3 --blk DIR --out P3H` wrote it. The imatrix has no head statistics, so the search is unweighted.
  - mac-metal searched on the M4 Max in 654 s, and pc-cuda on the RTX 4080 in 272 s. Both found the same seeds.
  - The `.blk` files differ only in the header's wall time (bytes 48 to 55). The packed shards are equal byte for byte.
  - Relative errors: gate 0.12080, up 0.12070, down 0.12062. The head's experts take 1.26 GB, not 1.57 GB.
- RTX 4080: pc-cuda's PC (Windows, RTX 4080 16 GB that drives the desktop, Ryzen 7 5800X3D, 128 GB DDR4-3200). A cl build
  of `83b73b9`, which has D1 (`c7a58b0`). Pinned experts, the automatic cache, the default VRAM reserve. No other programs
  ran. The least available RAM was 54.8 GB.
- M4 Max: mac-metal's Mac, `764cd13`. Before its runs, each pack was read once into the page cache.
- Both: greedy, at most 256 tokens, the code and chat prompts of
  [MTP drafts on the RTX 4080, again](2026-11-05-qwen38-mtp-4080-rerun.md).

```bash
nslm-qwen4-gen --model P3H --prompt-file PROMPT --max-tokens 256 --expert-cache-gb -1 --drafts K
```

## Notes

- The text is the same for each prompt with both packs and at every draft count, on each machine (md5 of stdout).
- Gate DA asks for at least 3,100 slots with 1 to 3 drafts. P3H keeps 3,101, 3,071 and 3,008, so DA passes at 1 draft
  only. Each extra draft keeps one more copy of the recurrent state in VRAM.
- Hypothesis HD1 (3% to 5% faster with drafts) holds for code (7.7% to 9.2%) and partly for chat (0.4% to 4.0%).
- With the head in the cache, the misses with drafts fall by 6% to 12%. Drafts still lose to no drafts on the 4080:
  code at 1 draft is 6% slower, chat 11%. Each verify row still pays the PCIe copies of its missed experts.
- Chat drafts are accepted less often with P3H. The unweighted head search may cause this. A search weighted by the
  head's own activation statistics may close the gap.
- On Metal, seed experts take more ALU work than Q4 experts, so each draft costs a little more.
- The 4080's second round stopped after 3 runs: something outside the agent stopped its shells. Those runs agree with
  round 1 within 0.4 tokens per second, except P3 code at 1 draft (31.70 against 33.90).
- On the M4 Max, P3 code without drafts gave 44.7 in round 1 and 39.7 in the three other runs of the same pack.
  The Mac's agent takes 39.7 as the machine's state in that session.

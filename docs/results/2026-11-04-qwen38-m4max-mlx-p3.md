# Qwen3.8-Flash-Next-NanoSeedLM-P3 in mlx-vlm on the M4 Max (2026-11-04)

**Result.** In mlx-vlm on an M4 Max, the P3 pack decodes at 34 tokens per second, as fast as a 4-bit affine model. Its
MLX peak memory is 65.5 GB, 8.7 GB less than the affine model's 74.3 GB. The text of all three P3 runs was coherent.

**Status.** Current. Spotlight indexed the new folders during the runs, so the numbers are noisy. The prompt had 18
tokens, so the prompt speeds do not show the speed of long prompts.

## Setup

- Machine: M4 Max, 128 GB, macOS 27.2, on AC power, GPU wired limit 110 GB.
- Machine state: memory 95% free. Spotlight (`corespotlightd`) used 1.4 to 2.5 cores during the runs. The P3 files were
  in the page cache. The first run of the reference read from the SSD.
- Software: mlx-vlm 0.7.12, mlx 0.32.4.
- Models, each through an SSD-PLE view (`prepare_external_ple_model`), so the 32.0 GB of Q4 PLE rows stay on the SSD:
  - [Qwen3.8-Flash-Next-NanoSeedLM-P3](https://huggingface.co/txgsync/Qwen3.8-Flash-Next-NanoSeedLM-P3), 98.2 GB.
  - The reference: Matt's oQ4e quantization of Qwen3.8-Flash-Next (affine 4-bit, group 64), with MTP.
- Sampling: the checkpoint's defaults (temperature 1.0, top_p 0.95, top_k 20). The chat template turns thinking off.
- Command (two runs for each model, by the mac-metal agent):

```bash
python -m mlx_vlm.generate --model PACK-ssd-ple --trust-remote-code --prompt "Why do tide pools matter?" --max-tokens 256 --verbose
```

18 prompt tokens and 256 generated tokens (the limit) in each run.

## Notes

- The P3 answers covered biodiversity, nursery habitat, food webs, research and climate signs. They had no loops and no
  broken tokens. The runs used sampling, so their texts differ.
- One prompt is weak evidence of quality. Read
  [The Qwen3.8-Flash-Next seed packs against the 4-bit MLX model](2026-11-04-qwen38-kld-vs-4bit.md) for KL divergence.
